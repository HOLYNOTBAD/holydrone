# Directory index

Paths below are relative to the repository root. CAD file and component counts are not purchase quantities.

| Path | Contents |
| --- | --- |
| `Hardware/holydrone_*_v1.*` | Four main assemblies: ORIN NX, LubanCat 4, static towing, and pivoting towing |
| `Hardware/3dp4drone/` | Aircraft printing parts, source CAD, and the material library |
| `Hardware/3dp4drone/balloonstatictowing/` | Static towing bracket, balloon cup, sleeve, carbon rod model, and assembly notes |
| `Hardware/3dp4drone/balloontowing/` | Pivoting towing mechanism and the shared balloon envelope |
| `Hardware/3dp4drone/balloontowing/STL_打印件/` | Four printable parts: 05, 30, 31, and 32 |
| `Hardware/3dp4drone/batteryholder/` | Shared battery holder |
| `Hardware/3dp4drone/camholder/` | 0°, 30°, and 90° camera mounts and mesh variants |
| `Hardware/3dp4drone/nxholder/` | Original NX brackets, modified LubanCat bracket, and hole-pattern checks |
| `Hardware/3dp4drone/receiver/` | Receiver bracket sources and modified variants |
| `Hardware/3dp4drone/rtk-ant holder/` | RTK antenna bracket |
| `Hardware/3dp4drone/side plate/` | Side plates and expansion-module mounting plates |
| `Hardware/3dp4exp/` | Ground experiment fixtures |
| `Hardware/3dp4exp/balloon static holder/` | Ground balloon fixture |
| `Hardware/3dp4exp/drone takeoff stand/` | Takeoff stands |
| `Hardware/3dp4exp/RTK base station/` | Three base-station STL parts |
| `Hardware/fasteners/` | Fastener models, including combined and mirrored models |
| `Hardware/modules/` | Purchased-module outlines and derived models |
| `Hardware/modules/LubanCat4/` | Original STEP and derived models with and without the bottom tray |
| `Hardware/modules/misc/` | Exchange formats and source download packages; some are active assembly dependencies |
| `Hardware/modules/misc/antenna-sma-915-mhz-for-lara-1.snapshot.2/` | Antenna STEP/FreeCAD sources and screenshot |
| `Hardware/modules/misc/C-RTK 2hp/` | Original C-RTK2Hp STEP and referenced SLDPRT |
| `Hardware/modules/misc/gxivision-s2m06-1.snapshot.6/` | Camera CAD download snapshot and screenshot |
| `Hardware/modules/misc/lipo-battery-2.snapshot.2/` | Referenced battery subassembly, parts, render, and texture |
| `Hardware/modules/misc/propeller-622.snapshot.2/` | Propeller STEP and screenshot |
| `Hardware/modules/misc/speedybee-f405-mini-bls-35a-1.snapshot.4/` | Original flight-controller/ESC STEP, SLDPRT, and screenshot |
| `Hardware/modules/misc/telemetry-cuav-air-link-4g-1.snapshot.3/` | Air Link 4G models in multiple formats; not enabled in the recorded main configurations |
| `Hardware/plates/` | Frame plate CAD |
| `Firmware/` | PX4 firmware |
| `Params/` | Flight parameter snapshots |
| `demo/` | CAD previews, reference video, and rendering records |
| `demo/real/` | Hardware photos, transparent cutouts, flight videos, and GIF previews |
| `demo/bom/` | Product images and source records |
| `demo/tools/` | CAD mesh export and preview rendering tools |

Original CAD filenames and folder names are preserved to maintain assembly references. See [BOM notes](BOM.md) for hardware selection differences.
