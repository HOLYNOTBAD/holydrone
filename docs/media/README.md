# 展示素材记录

2026-10-18 从当前主装配体实际零件几何生成。原始参考为 [holydrone explode.mp4](../../demo/holydrone%20explode.mp4)，1920×1080，约 6.073 秒：由合拢状态沿竖向分层展开。没有用该视频冒充新机型，也没有通过生成式图像补画零件。

| 素材 | 输入 | 内容 |
| --- | --- | --- |
| `holydrone_nx_v1-explode.gif` | `holydrone_nx_v1.SLDASM` / 默认配置 | ORIN NX 版本，独立提取 52 个启用且可见的叶子组件实例 |
| `holydrone_lbc4_v1-explode.gif` | `holydrone_lbc4_v1.SLDASM` / 默认配置 | 鲁班猫版本，独立提取 52 个启用且可见的叶子组件实例，含实际带底板鲁班猫与改装支架 |
| `*-assembled.png` | 对应动画合拢帧 | 静态装配预览 |
| `*-exploded.png` | 对应动画最大展开帧 | 静态展开预览 |

GIF 尺寸 960×720，循环播放；72 个输入帧按 80 ms 排布，总时长 5.76 秒。重复静止帧可能被编码器合并，编码帧数以实际验证结果为准。共用调色板 128 色。类别配色、光照和展示位移由渲染器指定，整体仍来自真实 CAD 网格和部件变换；不表达物理仿真、实际运动轨迹、装配工艺或产品实拍。

生成工具见 [tools](../tools/README.md)，输入/输出 SHA-256 与文件大小见 [media-manifest.json](../data/media-manifest.json)。README 使用相对路径嵌入 GIF，静态 PNG 供无法播放动画时查看。

两种牵引版的实物照片仍待补充。现有仓库图片只含零件截图/渲染/贴图；Notion 正文当前需要登录权限，没有用于此处的照片。补图时保留来源、机型、拍摄日期（若已知）与授权记录。
